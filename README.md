## Descripción
Este repositorio contiene el trabajo desarrollado por el grupo **PL3G** para la asignatura *Ingeniería de Servicios*.  
Incluye las prácticas realizadas durante el curso, con los ficheros de código necesarios para resolver todos los ejercicios y experimentos propuestos.

Junto con la memoria, que documenta en detalle todo el proceso de desarrollo de las prácticas, forma la entrega final del Proyecto de prácticas de la asignatura.

El objetivo del proyecto es adquirir los conocimientos prácticos relacionados con la parte teórica de la asignatura, aportando un estudio empírico y una visión práctica de la creación, despliegue, gestión y consumo de servicios tecnológicos.
